# Smart Waste Collection Tracker (MySQL edition)

This version keeps the supplied Flask templates/CSS and connects to an existing MySQL `smart_waste` database. It does not run the original Oracle SQL scripts.

## Setup (macOS)
1. Ensure MySQL is running and the `smart_waste` database already exists. Back up your database before project work.
2. In Terminal, from this folder: `python3 -m venv venv` then `source venv/bin/activate`
3. Install: `pip install -r requirements.txt`
4. Set credentials in Terminal (replace the password):
   `export MYSQL_HOST=127.0.0.1`
   `export MYSQL_PORT=3306`
   `export MYSQL_USER=root`
   `export MYSQL_PASSWORD='YOUR_MYSQL_PASSWORD'`
   `export MYSQL_DATABASE=smart_waste`
   `export SECRET_KEY='change-this-to-a-long-random-value'`
5. Create the login table automatically and seed demo logins: `flask --app run.py seed-users`
6. Start: `python3 run.py` and open http://127.0.0.1:5000

Demo logins: admin / admin123; supervisor / super123; worker / worker123 (only if a worker row exists). Change them after testing.

## Notes
- The app creates only the missing `app_user` table; it does not drop or rebuild existing tables.
- Your schema uses string IDs for bins, batches and vehicles; new IDs are generated by the app.
- Original `sql/01_schema_and_data.sql` and `sql/02_app_setup.sql` are Oracle scripts and must NOT be run on MySQL.
- The current MySQL schema has been inferred from the table descriptions shared by the project owner. Test each feature and review any schema mismatch errors before relying on it.
